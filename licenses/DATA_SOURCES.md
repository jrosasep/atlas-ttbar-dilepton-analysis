# Créditos y licencia de los datos

Los datos originales pertenecen a las publicaciones de **ATLAS Collaboration**
en CERN Open Data Portal. Los archivos se distribuyen bajo **CC0 1.0 Universal**;
ATLAS solicita citar los datos y reconocer a la colaboración. CERN y ATLAS no
respaldan automáticamente los trabajos que utilizan estas muestras.

- ATLAS Collaboration (2025). *ATLAS ROOT ntuple format Run 2 2015+2016
  proton-proton collision data beta release, 2J2LMET30 skim*.
  [DOI: 10.7483/OPENDATA.ATLAS.0CJR.N7ZT](https://doi.org/10.7483/OPENDATA.ATLAS.0CJR.N7ZT).
- ATLAS Collaboration (2025). *ATLAS ROOT ntuple format MC simulation,
  2015+2016 proton-proton collisions beta release, 2J2LMET30 skim*.
  [DOI: 10.7483/OPENDATA.ATLAS.NNF8.76IX](https://doi.org/10.7483/OPENDATA.ATLAS.NNF8.76IX).

Se usan los 16 archivos de colisiones del primer registro y 47 muestras de
simulación enumeradas en analysis/manifest.json, no todos los 373 archivos del
segundo registro. Las tablas CSV y JSON de este repositorio son resultados
derivados mediante el código incluido; no son nuevas colisiones ni los ROOT.

Los ROOT no se incluyen en Git. El manifiesto y el descargador permiten recuperar
los archivos exactos desde CERN y verificar sus checksums. El código y sus
adaptaciones no quedan cubiertos por la licencia CC0 de los datos.
